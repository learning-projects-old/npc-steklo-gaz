# ТОК 26 — Расчёт электрического режима стекловаренной печи

Оконная программа расчёта токов и напряжений электродной системы стекловаренной печи.
Расчёт выполняется на Python; готовые Windows x64 EXE содержат интерпретатор и библиотеки.
Для запуска **не нужны Python, DOSBox, DOS и подключение к сети**.

## Запуск

1. Откройте `dist/update-fast/TOK26-fast.exe` двойным щелчком.
2. Нажмите «Пример токов» либо «Пример поля»: результат рассчитывается сразу.
3. Для своей печи нажмите «Открыть данные…». 375 распознаваемых примеров встроены в EXE.
4. Посмотрите вкладки «Результат», «Геометрия и токи» и «Поле мощности».
5. «Сохранить результат…» записывает JSON с данными, параметрами, токами, матрицами и ошибками мощностей.

Исходные DAT не изменяются. В редакторе меняется только копия в памяти.
Файлы читаются в DOS-кодировке CP866. Числа — с десятичной точкой, разделитель — пробел или перевод строки.
Единицы сохраняются такими, как в исходной программе; автоматического перевода размеров и сопротивлений нет.

На главном экране слева виден оригинальный DAT, справа — понятная форма размеров печи,
таблица электродов и таблицы питания. Числа формы можно вводить с точкой или запятой.
Кнопки у DAT переключают оформление пар одной строкой/по строкам, не меняя числа.
DAT и форма синхронизируются автоматически каждые 300 мс. Ячейку таблицы подтвердите
Enter либо переходом в другое поле. Незавершённый или ошибочный DAT сохраняется в редакторе,
рядом появляется пояснение; расчёт по устаревшей форме запрещён. Оформление исходного
текста сохраняется при изменении чисел без изменения структуры.
Ошибки DAT указывают строку и причину: например, лишние пары и несуществующие номера
электродов. Вывод результатов округлён до двух знаков; расчёты и экспорт сохраняют
полную точность. Кнопки примеров блокируются до получения результата; промежуточного
переключения на исходные данные при запуске примера нет.
После изменения размеров печи проверяется попадание координат в границы:
X от −L/2 до L/2, Y от 0 до H. Форма перечисляет электроды за пределами ванны;
расчёт блокируется до исправления координат или размеров. Перемещение электродов
автоматически не выполняется. Изменение входных данных снимает устаревшие результаты.
«Схема связей» показывает пары линиями и позволяет менять их. Это пары разностей напряжений,
а не утверждение, что между электродами проложен провод.

Векторная диаграмма показывает токи либо напряжения; поворот на +30° и произвольный угол меняет
только изображение. Численные результаты и физический фазовый отсчёт расчёта сохраняются.
Для поля текущей печи есть отдельная кнопка прямо во вкладке «Поле мощности».

### Многопроцессорная версия

Единственная сборка находится в `dist/update-fast/TOK26-fast.exe`.
Версия FAST использует доступные логические процессоры
для независимых строк поля PLOT6 (до 51 процесса по числу строк). Процессы сохраняются
между расчётами. Последовательный подбор напряжений PTOK не распараллеливается.
Параметр CLI `--workers N` задаёт число процессов явно.

На данном компьютере (12 логических процессоров) контрольный PLOT6: последовательный
расчёт 0,091 с, первый многопроцессорный 1,071 с, повторный 0,028 с (медиана 10 запусков
из Python). Первый запуск медленнее из-за создания процессов; ускорение зависит от
данных и нагрузки. Все 6987 узлов точно совпадают с обычной версией. Время построения
карты интерфейсом в эти измерения не входит.

## Если исходный файл неполный

Нулевые радиус или длина в заголовке означали ручной ввод в DOS. Укажите соответствующие
значения в столбцах «Радиус» и «Длина электрода» таблицы электродов.

Если пар напряжений меньше N−1, нужны дополнительные уравнения схемы. Каждая строка содержит
N коэффициентов при комплексных токах электродов, затем действительную и мнимую части правой части.
Например, для трёх электродов `1 1 0 0 0` означает `I₁ + I₂ = 0`.

Таблица «Для специалиста» → «Условия соединения» содержит эти коэффициенты.
Кнопка изолированных источников строит такие уравнения по связным группам заданных
пар. Применяйте её **только если источники соответствующих групп действительно изолированы**.
Уравнения видны до расчёта и могут быть исправлены. Эта схема не подставляется автоматически.

В старой программе для части плоских схем запрашивалась перенумерация электродов. Здесь порядок
электродов совпадает с порядком пар концов в DAT. Если ранее использовалась другая нумерация,
нужно согласовать пары, коэффициенты мощностей и дополнительные уравнения с этим порядком.

## Что перенесено

- Основной сценарий `TOKP.EXE` / PTOK: круглые и плоские электроды, сопротивления, комплексные токи,
  подбор напряжений для заданных мощностей нескольких силовых групп.
- Текстовые DAT с заданными комплексными напряжениями: расчёт электродных токов.
- Геометрия электродов и векторная диаграмма токов средствами Tk, без ГРАФОР.
- PLOT6: пространственное поле плотности мощности, сетка 51×137, линейная/логарифмическая карта.
- Сценарии TOK и TOKP1; сверены с исходными EXE на контрольных данных.
- Чтение и запись двоичных TOKGR.DAT, просмотр существующего IST.DAT.
- Экспорт IST.DAT, POLE.DAT, Y51X137.DAT и CSV с явными координатами.
- Калькулятор удельного сопротивления по формулам обоих UDSOPR.XLS, без Excel.
- Проверки формата, вырожденности системы и ограничение числа итераций.

Окна старого ГРАФОР и вывод на DOS-принтер заменены современными диаграммами и файлами.
Побайтовое совпадение всех текстовых отчётов не требуется; арифметика проверяется численно.
Для плоских электродов PLOT6 не применяется: исходная пространственная модель предназначена для круглых.

## Проверка соответствия

Формулы круглых электродов восстановлены из 16-битного машинного кода `TOKP.EXE`;
формулы плоских — из `TOKPL.FOR` с проверкой по той же программе. Листинги `.FOR` содержат
ошибки перепечатки и не являются пригодными к сборке исходниками.

Контрольные значения оригинала:

| DAT | U₀ оригинала | U₀ Python | Модули токов после округления |
|---|---:|---:|---|
| CIRCLE.DAT | 91.828060 | 91.828050 | 941, 944, 941 |
| BOX.DAT | 73.228100 | 73.228099 | 111, 112, 137 |

Python использует двойную точность вместо исходной одинарной. Незначительные расхождения последних
знаков ожидаемы. Детальное описание — `REVERSE_ENGINEERING.md`; машинные результаты сверки —
`evidence/oracle_comparison.json`. Проверка 120 исходных файлов без ручных дополнений означает
работоспособность расчёта, но сама по себе не доказывает совпадение каждого с DOS.

Дополнительно проверены 3 полные сетки PLOT6 (20 961 узел), два сценария TOKP1,
сценарий TOK и 30 сохранённых значений таблиц XLS. Результаты — `evidence/extended-comparison.json`
и `evidence/workbooks.json`. Максимальное нормированное отклонение PLOT6 около 0.00114%.
В исходном TOK.EXE найдено пустое имя выходного файла UNIT 6; для эталона исправлен только этот
один байт в исследовательской копии, математические инструкции не менялись.

## Командная строка

Используйте `dist/update-fast/TOK26-fast.exe`:

```powershell
.\dist\update-fast\TOK26-fast.exe calculate "..\ТОК1\CIRCLE.DAT" --output result.json
.\dist\update-fast\TOK26-fast.exe field "..\ТОК1\PLOT6.DAT" --output field.json --legacy-directory field-export
.\dist\update-fast\TOK26-fast.exe graphics "..\ТОК1\TOKGR.DAT" --output vectors.json
.\dist\update-fast\TOK26-fast.exe inspect "..\ТОК1\BOX.DAT" --output input.json
.\dist\update-fast\TOK26-fast.exe calculate "..\ТОК1\BESCWET\OSZ8.DAT" --parameters options.json --output result.json
```

Пример `options.json` для двух изолированных ограничений семиэлектродной схемы OSZ8:

```json
{
  "extra_equations": [
    {"coefficients": [1, 1, 1, 0, 0, 0, 0], "voltage": [0, 0]},
    {"coefficients": [0, 0, 0, 1, 1, 0, 0], "voltage": [0, 0]}
  ],
  "max_iterations": 10000
}
```

Допустимы также `radii` и `electrode_lengths`: массивы положительных чисел по порядку электродов.
В PLOT6 две величины заданного напряжения означают RMS и фазу в градусах. В режиме `calculate`
по умолчанию это Re/Im; для амплитуды и фазы укажите `--voltage-format amplitude_phase`.
В GUI формат виден в отдельном переключателе; для PLOT6 выбирается автоматически по имени примера.
Код возврата: 0 — успех, 2 — ошибка ввода/расчёта. Оконная сборка `TOK26-fast.exe` также принимает команды,
но для неё требуется `--output`, поскольку консоли нет.

## Сборка из исходников

Проверенная среда: Python 3.11.14 x64, PyInstaller 6.22.3, Windows x64.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m unittest -v test_tok
.\.venv\Scripts\python.exe analyze_corpus.py
.\.venv\Scripts\python.exe build.py
```

Для запуска исходников достаточно стандартной библиотеки Python с Tk:
`python tok_app.py`. Capstone требуется только инструменту `disassemble.py`, а не приложению.
`prepare_oracle.py` и `compare_oracle.py` служат разработчику для повторной сверки;
DOSBox используется исключительно как эталон старой программы при разработке.
