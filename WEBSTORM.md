# ТОК 26 в WebStorm

Откройте корневую папку проекта через **File → Open**. Общие конфигурации из `.run/`
попадут в список запуска. Название проекта хранится в `.idea/.name`, значки —
в `.idea/icon.png` и `.idea/icon_dark.png`.

| Конфигурация | Действие |
|---|---|

| ТОК 26 FAST — Запустить | Открывает многопроцессорный EXE |
| ТОК 26 — Подготовить среду | Создаёт Python venv и устанавливает зависимости сборки |
| ТОК 26 — Собрать EXE | Собирает единственный EXE с названием и значком в `native/dist/update-fast/` |
| ТОК 26 — Проверки | Проверяет расчёты, синхронизацию и готовые EXE |

Для запуска готовых EXE Python не нужен. Для сборки нужен Windows x64, Python 3.11+
с Tk и доступ к PyPI при подготовке среды. Перед повторной сборкой закройте запущенные
EXE из `native/dist/update-fast/`, чтобы Windows разрешила заменить файлы.

Выберите конфигурацию и нажмите зелёный треугольник **Run**. При первом открытии на
другом компьютере сначала выполните «Подготовить среду», затем «Собрать EXE» и «Проверки».
Если Python не найден автоматически, выполните в терминале WebStorm:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File native/ide.ps1 -Action Setup -PythonPath 'C:\путь\к\python.exe'
```

Используется встроенный плагин **Shell Script**, а не Python-отладчик WebStorm.
Если конфигурации недоступны, проверьте **Settings → Plugins → Shell Script**.
Схема запуска соответствует [документации JetBrains](https://www.jetbrains.com/help/webstorm/run-debug-configuration-shell-script.html).

В коммите хранятся исходники, общие конфигурации, значки, описание версии и готовые
EXE. Личная среда `.venv`, промежуточная сборка `build`, кэш IDE и прежние EXE исключены.
